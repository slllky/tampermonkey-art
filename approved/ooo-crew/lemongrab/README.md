# Earl of Lemongrab

![Lemongrab blinking, marching, inspecting and shouting](motions.gif)

Approved for Ooo Crew. This fan sprite art was generated from the supplied character references, then cropped, scaled and aligned by the boots. The character is from *Adventure Time*.

Each 128 × 128 cell faces right and has its foot pivot at (64, 120). Frame bounds in the map are relative to the cell and exclude the right and bottom edges. To try the interactive preview, download the HTML file and open it in your browser.
